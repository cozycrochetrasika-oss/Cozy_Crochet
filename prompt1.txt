PHASE E — MOTION PHILOSOPHY

Do NOT make the entire commerce interface a WebGL application.

Use one optimized R3F/Three.js hero environment.

Possible visual concept:
- yarn ball
- crochet flower forms
- looping thread
- extremely subtle pointer parallax
- softly floating yarn ornaments

Use CSS/Motion for ordinary product cards.

GSAP/ScrollTrigger only where cinematic scroll motion adds value.

Lenis provides smooth scrolling.

Implement prefers-reduced-motion.

No animation should prevent:
- clicking
- keyboard navigation
- scrolling
- checkout
- reading product information.

Performance rules:
- dynamically load 3D
- cap DPR
- suspend/pause animation offscreen
- pause when document is hidden
- avoid separate WebGL scenes per product
- preload only essential hero resources
- video preload=metadata
- lazy-load below-fold product images
- use optimized images
- maintain minimal layout shift.
